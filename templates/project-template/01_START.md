# Stage 1 — Start

> Project Stage: 01  
> Purpose: Help the learner understand the project, prepare the required environment, and begin with a clear first action.

---

# Stage Purpose

The Start stage helps the learner enter the project without unnecessary confusion.

At this stage, the learner should understand:

- what will be built,
- what tools are required,
- what visible result is expected,
- what prior knowledge is assumed,
- what the first action should be.

This stage should reduce uncertainty.

It should not begin with extensive theory.

The learner should be able to answer:

```text
What am I making?

What do I need?

What should happen first?
```

# What Not to Do Yet

At this stage, do not:

- redesign the project,
- add new features,
- change multiple files,
- optimize the code,
- study the entire architecture,
- connect private Runtime services,
- create project-specific Reflection data,
- force GitHub setup before execution.

The purpose of this stage is only to prepare a reliable starting point.

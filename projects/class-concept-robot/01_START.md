# Stage 1 — Start

> Project Stage: 01  
> Project: Class Concept Robot  
> Purpose: Begin with a familiar robot project before introducing the idea of a class.

---

# Welcome

Welcome to your first Fribot Learning project.

At first glance, this project looks like a simple robot programming exercise.

However, this project is **not** primarily about making a robot move.

It is about discovering why software changes its structure as projects become larger.

By the end of this project, you should begin asking a new question.

> **Why do programmers eventually stop writing only functions and begin creating classes?**

You are **not** expected to know the answer today.

The purpose of this project is to let that answer emerge naturally through experience.

---

# What You Will Build

You will work with a small robot program.

The robot will perform simple actions such as:

- moving,
- stopping,
- changing speed,
- responding to input.

The robot itself is not the goal.

It is simply the environment where software structure becomes visible.

---

# What You Will Experience

This project follows one simple learning journey.

```text
Run a working robot

↓

Change one small part

↓

Observe the result

↓

Notice growing complexity

↓

Discover a better structure
```

Rather than memorizing new programming syntax,

you will experience **why software structure evolves.**

---

# Project Goal

The goal is **not** to memorize C++ class syntax.

The goal is to recognize that software naturally reaches a point where:

- related information should stay together,
- related behavior should stay together,
- one responsibility should belong to one place.

This is the beginning of object-oriented thinking.

---

# Before You Begin

At this moment you do **not** need to understand:

- classes,
- objects,
- inheritance,
- polymorphism,
- design patterns.

You only need curiosity.

The project will gradually introduce each idea when it becomes useful.

Before writing any code,

answer this question privately.

> **What do you think a class is?**

Do not search for the answer.

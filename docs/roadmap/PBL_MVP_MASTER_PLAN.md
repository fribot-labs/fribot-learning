# PBL Coding Education MVP Master Development Plan

## Vision

Build a Project-Based Coding Education Platform that helps junior developers gradually acquire the thinking process of senior software engineers.

GitHub records **code evolution**.

InnerMirror records **decision evolution**.

Together they create a learning environment where developers continuously improve both their software and their judgment.

---

# MVP Objectives

The MVP focuses on five primary objectives.

1. Learn through real GitHub projects.
2. Record decision-making through Reflection.
3. Analyze learning context using InnerMirror Runtime.
4. Generate AI-assisted PBL Coaching.
5. Improve senior-level engineering thinking through Decision Review.

The MVP is successful when learners improve the quality of their technical decisions, not simply the amount of code they write.

# MVP Scope

- Reflection
- Manual GitHub Synchronization

- PBL Coaching
- Decision Review

- Growth Portfolio

Excluded

- GitHub Webhooks
- Automatic synchronization
- Background scheduler
- Organization management
- Multi-repository aggregation
- Enterprise features
- Commercial services

These items belong to future releases.

# Success Criteria

The MVP is considered successful when learners demonstrate improvement in:

- problem definition
- technical reasoning
- architectural thinking
- engineering judgment
- decision quality

Success is measured by learning quality rather than coding quantity.

---

# Long-Term Vision

Fribot is not simply a coding education platform.

It is a long-term engineering growth platform.

GitHub records how software evolves.

InnerMirror records how engineers evolve.

The combination creates an educational environment where developers continuously improve both their software and their ability to make better technical decisions.

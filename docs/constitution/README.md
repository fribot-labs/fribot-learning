# Constitution Documentation

This directory contains the repository-level constitutional guidance for the
`fribot-learning` repository.

Unlike the constitutional documents maintained in the
`innermirror-constitution` repository, the documents in this directory do
**not** define new constitutional principles.

Instead, they explain how the constitutional principles are implemented
within the Fribot Learning repository.

---

# Purpose

The Constitution repository defines:

> **Why the ecosystem exists.**

This directory defines:

> **How the Fribot Learning repository implements those constitutional
> principles.**

The documents here translate constitutional meaning into:

- learner-facing projects,
- repository development,
- educational documentation,
- project templates,
- architectural decisions.

---

# Constitutional Relationship

The relationship between repositories is:

```text
InnerMirror Constitution
```

This directory should never redefine constitutional meaning.

It implements constitutional principles within the learning repository.

## LEARNING_CONTENT_STANDARD.md

Defines the official educational content standard for learner-facing
materials.

It establishes how Starter Projects should be designed, including:

- learning progression,
- document responsibilities,
- comparison-based learning,
- explanation after experience,
- Reflection transition.

This document is the primary writing standard for future learning content.

---

## CONSTITUTIONAL_REVIEW_CHECKLIST.md

Defines the constitutional review process for learner-facing development.

Every significant Pull Request, Starter Project, or educational document
should be evaluated against this checklist before merge.

The checklist verifies:

- constitutional alignment,
- learner experience,
- repository responsibility,
- architectural consistency,
- documentation quality,
- security,
- long-term maintainability.

# Intended Audience

These documents are intended for:

- repository maintainers,
- project authors,
- Starter Project designers,
- educational content contributors,
- reviewers,
- future repository architects.

Learners are not expected to read these documents before beginning a
project.

They exist primarily to maintain long-term consistency across the
repository.

---

# Repository Responsibility

This directory defines:

- constitutional implementation,
- educational standards,
- repository review criteria.

It does **not** define:

- learner-facing project content,
- Runtime behavior,
- Landing behavior,
- constitutional authority.

Those responsibilities belong to other repositories or documentation
layers.

# Long-Term Vision

As the Fribot ecosystem grows,

new projects,

new learning domains,

and new educational technologies

should continue following the same constitutional principles.

These documents provide a stable implementation guide while allowing
individual projects to evolve independently.

The Constitution defines enduring educational meaning.

This directory defines how that meaning is consistently implemented within
the `fribot-learning` repository.

Projects may evolve.

Technology may evolve.

The constitutional learning principles should remain stable.

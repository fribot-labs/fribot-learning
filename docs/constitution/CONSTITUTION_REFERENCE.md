# Learning Principle Zero

The highest governing educational principle is:

> **Learning does not begin with explanation.**
>
> **Learning begins when expectation meets reality.**

Every learner-facing project should preserve this principle whenever
appropriate.

Projects should therefore encourage learners to:

- predict,
- execute,
- observe,
- compare,
- understand,
- reflect.

Explanation follows meaningful experience rather than replacing it.

---

# Repository Responsibility

`fribot-learning` implements the Learning Constitution through:

- Starter Projects,
- executable learning materials,
- project progression,
- comparison-based learning,
- educational documentation,
- learner-facing project experiences.

It does **not** implement:

- private Reflection interpretation,
- continuity analysis,
- long-term learner memory,
- coaching intelligence,
- identity interpretation.

Those responsibilities belong to the Runtime layer.

# Repository Design Rule

When introducing a new feature into `fribot-learning`, first ask:

> Does this feature create or improve a meaningful learner experience?

If the answer is yes,

the feature may belong in this repository.

If the feature instead performs:

- private Reflection analysis,
- coaching generation,
- continuity computation,
- Runtime reasoning,
- long-term cognitive interpretation,

it belongs to the Runtime rather than the Learning repository.
